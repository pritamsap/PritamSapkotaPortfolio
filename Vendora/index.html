Vendora - E-Commerce Platform

A scalable e-commerce platform built with Spring Boot, React, and MongoDB, featuring secure authentication, persistent shopping carts, and streamlined order management.

Project Overview

Vendora is a full stack e-commerce solution designed to handle complex shopping workflows with enterprise grade reliability. Built from October to December 2024, the platform combines modern web technologies with cloud infrastructure to deliver a seamless shopping experience.

Key Features

  • Session Based Authentication: Secure user authentication system ensuring protected access to user accounts and order history
  • Persistent Shopping Cart: Advanced cart management that maintains user selections across sessions with real-time updates
  • Order Lifecycle Tracking: Robust order management system with state validation across complex checkout workflows, from cart to delivery
  • Scalable Architecture: Built with Java Spring Boot backend and MongoDB for flexible data management and high performance
  • Cloud Deployment: Containerized using Docker and deployed on Google Cloud for reliable, scalable hosting
  • Comprehensive Testing: Achieved 80% test coverage across all critical API endpoints using MockMvc and Mockito

Technology Stack

Backend: Java Spring Boot, MongoDB
Frontend: React
Infrastructure: Docker, Google Cloud
Testing: MockMvc, Mockito
